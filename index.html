MUNDO SALUD MÉDICA

Portal de Programación de Turnos

Sistema centralizado para la creación, validación horaria, auditoría y consolidación de cuadros de turnos asistenciales para Unidades Operativas y Dirección de Operaciones.

🏥
Unidades Operativas

Generador de Turnos

Módulo para jefes de área y coordinadores de servicios asistenciales. Permite construir y validar la matriz mensual de turnos sin errores matemáticos.

  • Cálculo automático de horas mensuales por colaborador
  • Asignación interactiva por convenciones (D, N, L, M, T)
  • Guardado y recuperación de progreso en almacenamiento local / JSON
  • Exportación estandarizada en formato Excel con estilos institucionales

Dirección de Operaciones

Consola DOE

Módulo para la Dirección de Operaciones y Enfermería (DOE). Diseñado para la importación, auditoría, ajuste de horas, aprobación o rechazo de programaciones.

  • Importación automática de Excels enviados por Unidades Operativas
  • Auditoría y verificación multi-servicio centralizada
  • Edición dinámica de convenciones y parámetros de evaluación
  • Exportación consolidada de cuadros aprobados para nómina

⚡

Cero Instalación

Funciona al 100% en el navegador de manera autónoma, sin necesidad de servidores backend o bases de datos complejas.

📊

Compatibilidad Excel

Importa y exporta libros `.xlsx` manteniendo formato institucional, colores de turnos y tablas resumen.

🔒

Privacidad & Respaldo

Los datos permanecen seguros en tu equipo local con opción de guardar y cargar archivos `.json` de respaldo.

✨

Validación en Tiempo Real

Conteo preciso de horas acumuladas para garantizar el cumplimiento de normativas de jornada laboral.
